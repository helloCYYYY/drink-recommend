## 修复 iPhone 16 Pro 全屏底部按钮被遮挡
- 现象：在 iPhone 16 Pro 全屏（手机端/≤480px）打开网页时，底部操作条（随机惊喜/重选，`.footer`）看不到。
- 根因：`@media (max-width:480px)` 里 `.phone{height:100vh}`。iOS Safari 的 `100vh` 把地址栏+底栏也算进高度，使容器比**可视区**更高；`.footer` 是 `position:absolute; bottom:13px`，被推到浏览器 UI 下方看不见。桌面预览（402×874 居中卡片，footer 在 874 内）不受影响。
- 修复（index.html 4 处，已 push 上线，commit 11462a2）：
  1. `body` 高度加 `min-height:100dvh` 回退（写在 `100vh` 之后）。
  2. 手机端 `.phone{height:100vh; height:100dvh; ...}` —— dvh=dynamic viewport height=当前可见区，不受地址栏影响（不支持 dvh 的浏览器回退 vh）。
  3. `.scroll` 内边距改为 `padding:max(54px,env(safe-area-inset-top)) 20px max(120px,calc(120px+env(safe-area-inset-bottom)))`，避开灵动岛与 Home Indicator，且内容不被底部 footer 遮挡。
  4. `.footer{bottom:max(13px,env(safe-area-inset-bottom))}`，全屏/PWA 模式下避开 Home Indicator。
- viewport 早已 `viewport-fit=cover`，故 `env(safe-area-inset-*)` 生效。
- 验证：`git fetch` 远程 master=11462a2；raw index.html 含 100dvh×2、safe-area×3。GitHub Pages 自动构建后手机刷新即可见底部按钮。
